## 1. 产品概述

ArtCam 是一款基于浏览器摄像头与手部姿态识别的实时艺术创作工具。用户通过双手食指与拇指的捏合动作，在摄像头画面上"摆放"矩形画框，每个画框内会随机应用一种内置艺术效果（200+ 种）。多个矩形可自由叠加，重叠区域以最新放置的效果为准，最终生成独一无二的合成艺术作品。

- 目标用户：喜欢即兴视觉创作的普通用户、艺术家、Vlogger、直播创作者
- 解决问题：让没有专业 PS/绘图技能的人也能用手势在真实环境上"涂鸦"出富有艺术感的画面
- 价值：零门槛、零安装、即开即用的浏览器手势艺术创作平台

## 2. 核心功能

### 2.2 功能模块

1. **Welcome 欢迎页**：极简艺术首屏，介绍 ArtCam 并引导进入创作
2. **Canvas 创作页**：摄像头预览、双手识别、矩形预览、艺术效果应用、作品保存
3. **Gallery 图鉴页**：浏览全部 200+ 内置艺术效果

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |

| Welcome | Hero | 极简艺术首屏 + 大字标题 + 进入按钮 + 背景粒子动画 |
| Canvas | 摄像头预览 | 实时镜像预览，权限请求与错误提示 |
| Canvas | 手部追踪 | MediaPipe Hands 21 点骨架绘制（可隐藏） |

| Canvas | 底部工具栏 | 随机/指定/撤销/清空/保存/骨架切换 |
| Gallery | 效果网格 | 200+ 效果缩略图网格，按分类筛选 |

## 3. 核心流程

用户打开网站 → 授权摄像头 → 双手入镜 → 各自食指与拇指接近 → 实时矩形预览（双手中点为对角顶点）→ 双手同时捏合确认 → 随机选择艺术效果 → 写入矩形区域到持久艺术层 → 继续摆放 / 撤销 / 清空 / 保存 PNG

## 4. 用户界面设计

### 4.1 设计风格

- **主题**：极简艺术暗色（参考 Apple Motion / Material 3 Expressive）
- **主色**：背景 `#0a0a0c`，前景 `#f5f5f7`，分割线 `#1c1c20`
- **强调色**：朱砂红 `#ff3b30`（主操作）+ 调色板渐变（青 `#22d3ee`、品 `#ec4899`、黄 `#f5b942`、橙 `#fb923c`、紫 `#a78bfa`）
- **字体**：Display 用 "Fraunces"（衬线艺术感），Body 用 "Inter Tight"，代码用 "JetBrains Mono"
- **按钮风格**：胶囊形 + 半透明玻璃质感 (backdrop-blur)
- **布局风格**：全屏 Canvas 为主，工具栏浮于底部，无卡片式容器
- **图标**：Lucide React 线性图标
- **动画**：framer-motion 微交互，捏合触发时矩形有缩放反馈与粒子飞溅

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |

| Welcome | Hero | 大字标题 ArtCam + 副标题 + 进入按钮 + WebGL 背景粒子 |

### 4.3 响应式

桌面优先（手势识别需要摄像头视野），移动端适配竖屏，触控工具栏图标加大，性能模式自动降级到 480p@30fps。

### 4.4 WebGL 场景指引

- **纹理链**：摄像头帧 → WebGL texture → 全屏四边形 → 屏幕输出
- **持久艺术层**：FBO 累积绘制，每次捏合触发一次矩形 quad 绘制
- **效果着色器**：fragment shader 接收 `uv + time + params + videoTex`，输出 RGBA
- **复合输出**：video 背景 × art 层 alpha 合成 + 可选手部骨架 Canvas2D 叠加
- **性能预算**：桌面 60fps @ 720p；移动 30fps @ 480p；捏合时瞬时绘制不卡顿
